# VoltShift: Autonomous Grid Load-Shifting Agent

Refer to the main [README.md](../../README.md) in the project root for full architecture diagrams, algorithm documentation, and setup instructions.

### Quick Start
- **Backend (Python / FastAPI)**:
  ```bash
  cd backend
  pip install -r requirements.txt
  uvicorn app.main:app --reload --port 8000
  ```
- **Frontend (Vite / React / TypeScript / Mapbox)**:
  ```bash
  cd frontend
  npm install
  npm run dev
  ```
